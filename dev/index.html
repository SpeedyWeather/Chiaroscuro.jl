Quick start

After the Installation copy and paste this into your Julia REPL, notebook etc

using SpeedyWeather, Chiaroscuro

# define albedo as a function of Cartesian coordinates on the unit sphere
f(x, y, z) = 0.1 + 0.6 * abs(z)     # bright poles, dark tropics
albedo = ChiaroscuroAlbedo(f)

# TODO: complete once the interface in src/ is final
evaluate(albedo)

Installation

First install Julia via juliaup (the recommended default way). Chiaroscuro.jl is a Julia package so from the Julia REPL you can then do

julia> ] add https://github.com/SpeedyWeather/Chiaroscuro.jl, SpeedyWeather

where ] opens Julia's package manager interactively. SpeedyWeather is a dependency anyway and you will need its exported function and types to run a simulation. Equivalently, you can do

using Pkg
Pkg.add(url="https://github.com/SpeedyWeather/Chiaroscuro.jl")
Pkg.add("SpeedyWeather")

and after all dependencies are installed with julia> using Chiaroscuro, SpeedyWeather you load the packages, ready to look on the bright side of light!

You can use this software in different ways,

  • in VS Code
  • via IJulia in Jupyter notebooks
  • in Pluto notebooks
  • in the Julia REPL (the standard terminal)
  • or oldschool via julia my_script.jl

Coming from Python? Have a look at a concise list of noteworthy differences.

Julia Jupyter kernel

To install a Julia kernel for Jupyter notebooks (assuming you already have jupyter notebooks installed) you need a package called IJulia

julia> ] add IJulia

After IJulia is installed do once

using IJulia
installkernel("Julia")

this will add a Julia kernel you can choose among other Python kernels in jupyter lab or jupyter notebooks.
